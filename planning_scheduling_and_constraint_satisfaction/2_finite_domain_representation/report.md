Ονοματεπώνυμο: Μερτζεμεκιανός Μάρκος

## Ανάλυση προβλήματος

Στο παρακάτω πρόβλημα αναγνωρίζονται οι οντότητες
- Ταχυδρόμος
- Τοποθεσία
- Γράμμα
- Γραμμή του μετρό( μπλε ή κόκκινη )

Επίσης στους κανόνες έγινε και η εξής υπόθεση:
Ότι άμα βρίσκεται σε μία γραμμή θα πρέπει να αποβιβαστεί από το μετρό και μετά να επιβιβαστεί στην άλλη γραμμή.

## Δήλωση σχέσεων

Ορίσθηκαν οι σχέσεις των δρόμων που μπορεί να διανύσει ο ταχυδρόμος με τα πόδια και ορίσθηκαν οι σχέσεις των γραμμών του μετρό. Επίσης ορίσθηκε σε ποιες γραμμές βρίσκονται οι μπλε σταθμοί και οι κόκκινοι σταθμοί.

## Μεταβλητές κατάστασης

Για τις μεταβλητές κατάστασης έγιναν οι εξής δηλώσεις
- οι τοποθεσίες των γραμμάτων, τα οποία μπορούν να βρίσκονται είτε σε μία τοποθεσία είτε σε έναν ταχυδρόμο είτε σε nil (έχει παραδοθεί)
- η τοποθεσία του ταχυδρόμου
- η γραμμή του μετρό που βρίσκεται ο ταχυδρόμος, αν δεν είναι σε καμία γραμμή τότε είναι nil

## Σχεδιασμός ενεργειών

Για το πρόβλημα σχεδιάστηκαν οι εξής ενέργειες:

### pick_letter( P: POSTMAN, L: LETTER, LOC: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να μαζέψει ένα γράμμα.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| loc_letter( L ) = LOC & loc_postman( P ) = LOC & is_on_metro_line( P ) = nil | loc_letter( L ) <- P |

### deliver_letter( P: POSTMAN, L: LETTER, B: BOX, LOC: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να παραδώσει ένα γράμμα σε μία τοποθεσία όπου περιέχει κουτί.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| loc_letter( L ) = P & loc_postman( P ) = LOC & postbox_loc( LOC ) & is_on_metro_line( P ) = nil | loc_letter( L ) <- nil |

### move_forward( P: POSTMAN, L1: LOCATIONS, L2: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να μετακινηθεί από μία τοποθεσία σε μία άλλη με τα πόδια.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| road_con( L1, L2 ) & loc_postman( P ) = L1 & is_on_metro_line( P ) = nil | loc_postman( P ) <- L2 |

### move_backward( P: POSTMAN, L1: LOCATIONS, L2: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να μετακινηθεί από μία τοποθεσία σε μία άλλη με τα πόδια. Η ενέργεια αυτή έγινε για να επιτρέψει στον ταχυδρόμο την αμφίδρομη μετακίνη.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| road_con( L1, L2 ) & loc_postman( P ) = L2 & is_on_metro_line( P ) = nil | loc_postman( P ) <- L1 |

### embark_blue_metro( P: POSTMAN, L: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να επιβιβαστεί στην μπλε γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| blue_station( L ) & loc_postman( P ) = L & is_on_metro_line( P ) = nil | is_on_metro_line( P ) <- blue |

### disembark_blue_metro( P: POSTMAN, L: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να αποβιβαστεί από την μπλε γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| loc_postman( P ) = L & is_on_metro_line( P ) = blue | is_on_metro_line( P ) <- nil |

### embark_red_metro( P: POSTMAN, L: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να επιβιβαστεί στην κόκκινη γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| red_station( L ) & loc_postman( P ) = L & is_on_metro_line( P ) = nil | is_on_metro_line( P ) <- red |

### disembark_red_metro( P: POSTMAN, L: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να αποβιβαστεί από την κόκκινη γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| loc_postman( P ) = L & is_on_metro_line( P ) = red | is_on_metro_line( P ) <- nil |

### move_blue_metro( P: POSTMAN, L1: LOCATIONS, L2: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να μετακινηθεί από μία τοποθεσία σε μία άλλη στην μπλε γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| blue_metro_con( L1, L2 ) & loc_postman( P ) = L1 & is_on_metro_line( P ) = blue | loc_postman( P ) <- L2 |

### move_red_metro( P: POSTMAN, L1: LOCATIONS, L2: LOCATIONS )

Η ενέργεια αυτή επιτρέπει στον ταχυδρόμο να μετακινηθεί από μία τοποθεσία σε μία άλλη στην κόκκινη γραμμή του μετρό.

| Προϋποθέσεις | Αποτελέσματα |
|--------------|---------------|
| red_metro_con( L1, L2 ) & loc_postman( P ) = L1 & is_on_metro_line( P ) = red | loc_postman( P ) <- L2 |

## Αρχικά δεδομένα και στόχοι προβλήματος

Τα αρχικά δεδομένα του προβλήματος είναι τα εξής:
- Ο ταχυδρόμος βρίσκεται στην τοποθεσία loc_14
- Ο ταχυδρόμος δεν είναι σε καμία γραμμή του μετρό
- Το γράμμα l2 βρίσκεται στην τοποθεσία loc_10
- Το γράμμα l1 βρίσκεται στην τοποθεσία loc_13

Οι στόχοι του προβλήματος είναι τα εξής:
- Το γράμμα l1 να παραδοθεί
- Το γράμμα l2 να παραδοθεί

Η λύση που δώθηκε από τον επιλυτή είναι η εξής

1) move_backward(p,loc_13,loc_14)
2) pick_letter(p,l1,loc_13)
3) move_backward(p,loc_8,loc_13)
4) move_forward(p,loc_8,loc_10)
5) pick_letter(p,l2,loc_10)
6) move_backward(p,loc_8,loc_10)
7) move_backward(p,loc_7,loc_8)
8) deliver_letter(p,l2,b,loc_7)
9) deliver_letter(p,l1,b,loc_7)

Γενικά επειδή δώθηκαν κινήσεις για την επιβίβαση και την αποβίβαση από το μετρό, ο επιλυτής αποφεύγει την επιβίβαση και την αποβίβαση από το μετρό.
